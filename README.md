# 존중하는 말하기 채점기

중학교 1학년 국어 수행평가 「존중하는 말하기 방법 소개하기」 발표를 들으며 예/아니오만 누르면 점수와 성취수준이 자동으로 계산되는 채점 도구입니다.

## 쓰는 법

1. **학급 설정**에서 학급 이름과 인원, 발표 시간 기준(기본 1분 30초 ~ 2분 30초)을 맞춥니다.
2. 학급과 번호를 고르고, 발표가 시작되면 **발표 시작**을 누릅니다.
3. 발표 순서대로 인트로 → 사례 1·2·3 → 아웃트로 → 비언어적 요소를 체크합니다.
4. **다음 번호 →**로 넘어갑니다. 반 채점이 끝나면 **엑셀로 저장**을 누릅니다.

## 채점 기준

| 항목 | 체크 | 점수 |
|---|---|---|
| ① 유형과 예시 | 사례마다 말한 유형(1~5) + 예시가 유형에 맞는지. 유형이 겹치거나 예시가 맞지 않으면 불인정 | 3개 7 · 2개 5 · 1개 3 · 0개 1 |
| ② 현실적 방안 | 사례마다 현실적이고 구체적인 개선 방안을 말했는지 | 3개 7 · 2개 5 · 1개 3 · 0개 1 |
| ③ 발표 구조 | 인트로, 아웃트로 | 둘 다 3 · 하나 2 · 없음 1 |
| ④ 비언어적 요소 | 시선, 표정, 자세·몸짓 | 3개 5 · 2개 3 · 1개 이하 1 |
| ⑤ 발표 시간 | 타이머 또는 직접 입력 | 범위 안 3 · 앞뒤 30초 이내 2 · 그 밖 1 |

합계 21~25 A, 16~20 B, 11~15 C, 6~10 D, 5 E. 발표 시간이 기록되기 전에는 합계를 내지 않습니다.

## 기록 보관

- 기록은 **각자 쓰는 브라우저에만** 저장되고 어디로도 전송되지 않습니다. 다른 선생님의 기록과 섞이지 않습니다.
- 학교 PC 복원 프로그램이나 브라우저 기록 삭제로 사라질 수 있으니, 반 채점이 끝날 때마다 **엑셀로 저장**하고 파일은 USB나 개인 클라우드에 보관하세요.
- 기록이 사라졌다면 **학급 설정 → 엑셀 백업 불러오기**에서 저장해 둔 파일을 고르면 체크 내역까지 되살아납니다.
